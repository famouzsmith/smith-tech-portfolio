# SMITH TECH Portfolio

The personal portfolio website for Smith Ishaku — Web Developer & Creative Designer.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel

## Local development

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

```powershell
npm run dev
npm run build
npm run start
npm run lint
```

## Content

All site text, services, projects, and social links live in `src/data/site.ts`.
